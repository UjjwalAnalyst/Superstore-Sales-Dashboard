# Superstore-Sales-Dashboard
Power BI dashboard analyzing Superstore sales to visualize profit trends, regional performance, customer segments, and product insights.
This project presents an interactive and insightful Superstore Sales Dashboard created using Power BI. The dashboard analyzes key metrics such as revenue, profit, regional performance, customer segments, product category trends, and shipping insights. It helps visualize business performance and identify improvement areas through dynamic filters, slicers, and drill-down capabilities. The goal of this project is to convert raw Superstore sales data into meaningful business intelligence using data modeling and visualization.
